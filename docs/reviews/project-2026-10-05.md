## Findings and fixes

| Area | Defect | Resolution |
|---|---|---|
| Runtime lifecycle | `ps` and non-SIGKILL `kill --all` omitted processes in child cgroups. Killing also lacked the lifecycle lock and could leave its temporary freeze behind on a read error. | Enumerate descendants, handle threaded cgroups, lock lifecycle changes, confirm freezing and restore the original freeze request. A real nested-cgroup test failed against the old binary. |
| Descriptor passing | A truncated SCM_RIGHTS message returned ENOBUFS after Linux installed eight descriptors, leaving them open. | Close installed descriptors from complete kernel-written control records before returning the error. The regression counts copies of the sent file's inode. |
| Client streams | A line that exceeded the NDJSON limit and completed in the same frame bypassed the size check. | Check complete lines before deserialization as well as unfinished data. A real HTTP response reproduces the boundary. |
| Compose recovery | Failure connecting an additional network left a new container with the desired hash but incomplete endpoints; the next `up` reused it. | Remove that incomplete new container and its anonymous volumes, preserve the original error, and warn if cleanup fails. A retry test verifies both networks. |
| Desktop logs | Unfinished logical lines could grow indefinitely despite the row count limit. | Bound per-stream line text and total retained text, show discarded-character counts, flush partial output on disconnect, and preserve CRLF across fragment boundaries. |
| Desktop forms | Enter could resubmit a pending action despite a disabled button, including duplicate container creation and cancellation/restart of a build. | Guard submission handlers; the Run dialog uses a synchronous latch across validation and creation. |
| Desktop reconnect | Logs/stats stayed disconnected if the daemon watch reconnected before the old stream reported EOF/error. | Compare the stream's opening generation when it ends as well as when the daemon generation changes. |
| Desktop teardown | GUI Down used labels alone and could delete formerly managed resources now declared external in the recorded files. | Load and validate current recorded files before mutations, preserve external resources, and remove all stack services/profiles. Stacks without recorded files retain label-based teardown. |
| Desktop startup | WebKit's POSIX `C` language tag caused uPlot's formatter to throw during import, leaving a blank window. | Validate the browser language before loading charts; use `en-US` only for invalid tags. Actual Chart/uPlot import tests cover `C`, `C.UTF-8`, `en_US`, and a valid locale. |
| CI | pnpm/action-setup looked for a root package.json, while the pnpm version is declared only in desktop/package.json. | Set `package_json_file: desktop/package.json`, using the [action’s package file input](https://github.com/pnpm/action-setup/blob/v4/action.yml). |

The suspected missing `run -w` directory creation was withdrawn: the runtime already creates the directory through its rootfs fd after mounts and before the read-only remount. No implementation change was needed.
